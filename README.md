# BIU Smart App

## Loyiha haqida
Buxoro Innovatsiyalar Universiteti uchun
korporativ mobil ilova.

## Texnologiyalar
- Expo (React Native) SDK 54
- Zustand (state management)
- Axios (HTTP client)
- expo-location (GPS)
- expo-local-authentication (Biometric)

## Ishga tushirish
1. npm install
2. cp .env.example .env
3. .env faylida API URL ni o'zgartiring
4. npx expo start

## Build
```bash
npx eas build -p android --profile preview
```
